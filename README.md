# Titanic Dataset EDA with LLM-Powered Insights

An interactive Exploratory Data Analysis (EDA) project built using Python, Pandas, Seaborn, Matplotlib, Gradio, and Ollama.
This project analyzes the Titanic dataset and provides AI-powered insights using Large Language Models (LLMs).

---

## 🚀 Features

* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* Interactive Data Visualization
* Correlation Analysis
* Missing Value Detection
* AI-Powered Insights using Ollama LLM
* User-Friendly Gradio Interface

---

## 🤖 Ollama Setup

Install Ollama from:

[Ollama Official Website](https://ollama.com/?utm_source=chatgpt.com)

Pull a model:

```bash
ollama pull llama3
```

Run Ollama locally before starting the app.
